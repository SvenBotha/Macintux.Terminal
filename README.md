# Macintux.Terminal

Terminal setup for macOS and Linux (Macintosh + Tux). Each tool will be a self-contained module:
`modules/<tool>/` holds that tool's config plus an `install.sh` that installs the tool and links the config.

Used as the `terminal/` submodule of [Macintux.dotfiles](https://github.com/SvenBotha/Macintux.dotfiles).

See [TASKS.md](TASKS.md) for the install checklist.
